# Changelog

## 0.2.0

- Found on your network: the page lists the UniFi OS consoles it sees (their sign-in page), with Use this; it fills
  the gateway address.
- The API key's help links straight to that gateway's Integrations page (`{url}/network/default/integrations`) to make
  the key; the Site Manager link moved to the address's help. No Sign in once: UniFi has no supported way to make an
  API key from a login.
